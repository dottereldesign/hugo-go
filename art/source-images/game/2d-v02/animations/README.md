# Outfit 03 animation generation log

## Generation mode

- Tool: built-in ImageGen
- Mode: new raster generation from approved workspace references
- Output: four 4 × 3 magenta-keyed PNG sheets
- Runtime use: none; approved silhouettes are extracted into individual files

## Shared identity and art direction

Use the approved Outfit 03 neutral-front and ready-profile PNGs as the hard
reference. Draw the same ten-year-old Japanese/New Zealand boy with a friendly
non-stereotyped face, dark fauxhawk with shaved sides, child proportions,
burnt-orange/cream/gold wingsuit, teal piping, navy protection, and the same
twin heel-jet shoes. Clean premium 2D game animation art, stable camera, stable
scale, readable silhouette, and flat magenta background. Exactly four columns
by three rows, read chronologically left-to-right and top-to-bottom. One
complete isolated full-body figure per cell; no labels, scenery, shadows,
cropping, overlap, duplicate limbs, or redesign.

## Production rule

These prompts describe chronological sheets, not a pool of interchangeable
poses. If any sheet fails continuity, regenerate that chronological section.
Never alternate drawings from several generations to fabricate more frames.
After approval, chroma-clean, extract, register, name, manifest, and review the
individual PNGs. The final review file is an exact copy of frame 01 and is not
played at runtime.
